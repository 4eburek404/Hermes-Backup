## Воспроизведение без LLM

Из корня чистого checkout, где опубликован пакет:

```bash
out="$(mktemp -d)/scores"
python3 evals/development-workflow/experiments/natural-routing-feature-shout-20261007/reproduce_scores.py --output "$out"
```

Путь `$out` должен быть новым/пустым. Скрипт использует только вложенные `source/` и сохранённые трассы/evidence, проверяет совпадение с записанными scores и не запускает Hermes, модель или API. Проверенный пересчёт приложен в `reassessments/verified-clean-copy/`; результат финального повторения из изолированной копии пакета — `clean-package-final-verification.json` (пустой output-каталог, exit code 0, 12 файлов, без LLM-запусков).
