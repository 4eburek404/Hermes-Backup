# GitHub Issue to Pull Request Route

Use this reference when an active GitHub issue should be carried through
orchestrated development and delivery. The canonical source of truth is
[`github-issue-to-pr`](../../../../github/github-issue-to-pr/SKILL.md); route
there for the workflow and its ownership boundaries.

The canonical orchestrator gathers live issue/thread state and repository
instructions, then hands the work, review, and delivery mechanics to their
specialized owners. This file is only a routing and handoff reference, not a
second workflow.
