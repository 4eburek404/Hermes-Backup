# Поиск авиабилетов Tutu

Для живого поиска используй штатный Hermes MCP tool Tutu `mcp__tutu__search_avia` с параметрами, соответствующими запросу пользователя. Получай фактические предложения от Tutu MCP; не используй `probe.py`, HTTP/curl или отдельный MCP-клиент как production transport.

Не меняй запрошенные маршрут, дату или состав пассажиров без необходимости. S1 обрабатывает историческую запись с `recorded_at` и не применяет календарное правило «дата должна быть в будущем».

Сообщай только предложения, цены, тарифы и условия, которые действительно присутствуют в результате MCP. Не додумывай неизвестные значения и не выполняй альтернативные поиски без причины.
