# S3 — ошибка инструмента Tutu не является пустой выдачей

Эта исполняемая спецификация защищает различие между ошибкой источника и
успешным поиском без предложений.

## Дано

Production-поиск вызывает `search_avia` через MCP SDK, а Tutu возвращает
tool-level error (`isError: true`) с текстом причины.

## Когда

Продукт обрабатывает этот ответ.

## Тогда

- ошибка не передаётся в обычный разбор успешной выдачи;
- продукт завершает поиск ошибкой;
- текст причины от Tutu сохраняется в ошибке;
- результат с `offers: []` не создаётся.

## Исполнение и граница проверки

Проверка выполняется без сети с подменённым MCP SDK result.
Она не определяет пользовательскую формулировку ошибки агентом и не покрывает
другие формы пустой выдачи из `meta`; для них нужны отдельные спецификации.
