# S3 — ошибка инструмента Tutu не является пустой выдачей

Эта исполняемая спецификация защищает различие между ошибкой источника и
успешным поиском без предложений.

## Дано

Запись `fixtures/avia/empty-route.json` содержит результат `search_avia` с
`isError: true` и полным текстом причины Tutu. Тестовый in-memory MCP `Server`
возвращает эту запись через типизированный результат настоящего MCP SDK 2.2.0.

## Когда

Production поиск вызывает `search_avia` через настоящий SDK client/session.

## Тогда

- ошибка не передаётся в обычный разбор успешной выдачи;
- поиск завершается исключением;
- полный текст причины Tutu сохраняется в сообщении исключения;
- результат с `offers: []` не создаётся.

## Исполняемая проверка и граница

[test_tool_error.py](../tests/test_tool_error.py)
::`test_tool_error_is_reported_as_error_not_empty_search` проверяет этот контракт.
Она использует SDK `Client`, session, `call_tool` и типы, подключённые к локальному
in-memory MCP `Server`; raw fixture не изменяется.

Проверка не использует HTTP или живой Tutu и не проверяет пользовательское
оформление ошибки CLI. Коды завершения и stderr CLI закрепляет
[S8](09-cli-errors.md). Спецификация не покрывает другие формы пустой выдачи
из `meta`.
