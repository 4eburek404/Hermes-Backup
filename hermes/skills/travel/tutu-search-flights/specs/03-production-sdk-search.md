# S2 — production-поиск через MCP SDK

Эта исполняемая спецификация защищает production-путь, которым skill выполняет
живой поиск. Сеть в проверке подменяется на границе MCP SDK; содержимое ответа
берётся из записанного raw Tutu response.

## Дано

Есть JSON-запрос поиска из `fixtures/avia/baseline.json` и соответствующий ему
raw ответ Tutu.

## Когда

Production-команда поиска получает этот JSON-запрос, а MCP SDK возвращает
записанный ответ.

## Тогда

- используется Tutu MCP endpoint `https://mcp.tutu.ru/mcp`;
- вызывается инструмент `search_avia` ровно один раз;
- аргументы передаются без изменения;
- команда завершается успешно;
- stdout содержит один JSON-результат поиска;
- результат соответствует тому же продуктовому представлению, которое защищает S1.

## Исполнение и граница проверки

Проверка детерминированная: реальная сеть и живой Tutu не используются.
Она защищает связку production CLI → MCP SDK → `search_avia` → разбор результата.
`make live` остаётся отдельной интеграционной проверкой доступности реального сервера.
